# BotsCorporation

> Telegram RPG / Economy / Moderation Bot

**BotsCorporation** — многофункциональный Telegram-бот для создания RPG-системы внутри групповых чатов.

Проект объединяет игровую RPG-механику, виртуальную экономику, пассивный доход, задания, достижения, кейсы, магазин, азартные мини-игры, персонажей, способности, ранги, модерацию и систему гибкой настройки каждого Telegram-чата.

Главная идея проекта — сделать бота, которого можно добавить в любой чат и практически полностью настроить под конкретное сообщество **без изменения исходного кода**.

# 💰 Экономика

В каждом чате существует собственная конфигурация экономики.

Администратор может изменить:

* название валюты;
* символ валюты;
* награду за сообщение;
* награду за фотографию;
* награду за видео;
* cooldown получения награды;
* доступность экономики;
* настройки ежедневных и часовых наград;
* настройки пассивного дохода;
* стоимость игровых команд;
* другие параметры экономики.

Поддерживается история транзакций.

Каждое изменение баланса фиксируется.

Это позволяет отслеживать:

* источник получения денег;
* размер операции;
* баланс до операции;
* баланс после операции;
* связанного пользователя;
* идентификатор игровой операции;
* дату операции.

# 👑 Система прав

Проект использует несколько уровней доступа.

## Founder

Founder — владелец самого бота.

Имеет доступ к глобальной административной панели.

Founder может:

* управлять чатами;
* управлять пользователями;
* управлять экономикой;
* создавать предметы;
* создавать расы;
* создавать способности;
* создавать ранги;
* управлять кейсами;
* управлять заданиями;
* управлять достижениями;
* изменять глобальные настройки.

Founder имеет максимальный уровень доступа.

---

## Chat Owner / Administrator

Администратор с максимальными правами внутри конкретного Telegram-чата.

Он может управлять конфигурацией **только своего чата**.

Например:

* изменить валюту;
* изменить награды;
* изменить cooldown;
* включить/выключить игры;
* настроить задания;
* настроить кейсы;
* настроить пассивный доход;
* настроить модерацию;
* изменить приветствие;
* применить готовый конфигурационный профиль.

При этом Chat Owner **не может**:

* выдавать валюту;
* изменять чужие балансы;
* создавать глобальные предметы;
* изменять расы;
* изменять способности;
* изменять глобальные ранги;
* выдавать системные привилегии;
* изменять настройки другого чата;
* получить права Founder.

# 🧩 Конфигурационные профили

Для быстрого запуска чата поддерживается система готовых профилей.

Например:

```text
classic_rpg
hardcore_rpg
social
chaos
```

Профиль представляет собой набор настроек.

После применения профиля бот автоматически настраивает выбранный чат.

Пример:

```text
/config preset classic_rpg
```

После применения:

* экономика получает готовые значения;
* награды устанавливаются автоматически;
* включаются необходимые механики;
* настраиваются cooldown;
* устанавливаются параметры игр;
* активируются задания;
* настраиваются пассивные доходы.

Профиль изменяет только конфигурацию чата.

Пользователи, кошельки, предметы, персонажи и другие игровые данные не удаляются.

# 🗃 Архитектура

Проект построен по многослойной архитектуре.

Основные уровни:

```text
Telegram
   │
   ▼
Handlers
   │
   ▼
Services
   │
   ▼
Repositories
   │
   ▼
SQLAlchemy
   │
   ▼
Database
```

### Handlers

Отвечают за Telegram-команды, callback-запросы и пользовательский интерфейс.

### Services

Содержат бизнес-логику.

Например:

* экономика;
* награды;
* игры;
* персонажи;
* задания;
* модерация.

### Repositories

Отвечают за работу с базой данных.

### Models

SQLAlchemy-модели базы данных.

# 🗄 База данных

Проект использует SQLAlchemy.

Поддерживаются:

* SQLite + aiosqlite;
* PostgreSQL + asyncpg.

SQLite подходит для локального запуска.

PostgreSQL рекомендуется для production/VDS.

# 🖥 Запуск

Для локального запуска рекомендуется:

* Windows / Linux;
* Python 3.12;
* виртуальное окружение;
* SQLite для разработки.

Пример:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создайте `.env` на основе шаблона конфигурации проекта.

После заполнения токена:

```bash
python -m app.main
```
